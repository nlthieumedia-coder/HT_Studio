# HT Dola Studio 1.0.0

Ngày build: 2026-09-21

Bản phát hành ổn định đầu tiên cho Windows x64 gồm quản lý dự án/job, queue/worker an toàn, profile Chromium bền vững cho phiên được ủy quyền, provider Dola fail-safe, quản lý đầu ra, chẩn đoán và backup/restore.

- Đây là INTERNAL / PRIVATE release. Installer chưa ký số; Windows có thể hiển thị SmartScreen. Trạng thái này không phê duyệt public distribution.
- Người dùng tự đăng nhập Dola; không có CAPTCHA bypass, fingerprint spoofing, stealth hoặc tạo tài khoản tự động.
- Dữ liệu nằm tại `%APPDATA%\HT_Dola_Studio\data`; browser tại `%APPDATA%\HT_Dola_Studio\browsers`.
- Installer không chủ động xóa dữ liệu người dùng.

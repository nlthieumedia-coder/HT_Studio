# Quick Start — HT Dola Studio 1.0.0

1. Chạy `HT_Dola_Studio_1.0.0_Setup.exe`.
2. Hoàn tất hướng dẫn lần đầu và kiểm tra Storage, Browser, FFmpeg, worker, backup.
3. Tạo Project rồi nhập/tạo scene và job.
4. Trong Accounts, tạo profile và mở Chromium hiển thị để tự đăng nhập; ứng dụng không lưu mật khẩu.
5. Chạy **Check Session**, sau đó đưa job vào queue. Giữ mặc định một worker ở lần chạy đầu.
6. Tạo Data Backup trước khi nâng cấp hoặc chạy khối lượng lớn.

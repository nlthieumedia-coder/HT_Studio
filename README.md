## Yêu cầu hệ thống

- Windows 10 hoặc Windows 11, kiến trúc 64-bit.
- Kết nối Internet ổn định.
- Google Chrome đối với HT Vids Studio.
- Tài khoản và quyền truy cập dịch vụ tương ứng do người dùng tự quản lý.

## Cài đặt an toàn

1. Chỉ tải tệp từ các nút chính thức ở trên.
2. Có thể đối chiếu SHA-256 trước khi chạy tệp.
3. Windows SmartScreen có thể cảnh báo vì ứng dụng chưa có chứng thư Code Signing; chỉ chọn **More info → Run anyway** khi đường dẫn tải thuộc repository chính thức này.
